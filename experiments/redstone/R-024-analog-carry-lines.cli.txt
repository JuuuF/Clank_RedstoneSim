# R-024: analog carry lines (doc/redstone/records/R-024-analog-carry-lines.md)
# Two wire lines carry every carry of a 4-bit adder at once. Each bit of the line is three wires
# (a lower wire on stone, a wire on glass one higher, a wire on stone): the step up onto glass
# passes power one way only (R-019), so each bit's injection reaches only the bits above it.
# Bit j injects 15 into the G line if it generates a carry (A=B=1), into the K line if it kills
# it (A=B=0). Strength falls 1 per wire, so at bit i the line whose nearest injection lies
# closest below i is the stronger one; a subtracting comparator per bit (rear: G line through
# its support block, side: a wire stepping down from the K line) is on iff C_i = 1.
#   G line z=0: lower wires 3j 3 0, glass 3j+1 3 0, stone 3j+2 3 0; K line z=2 shifted +1 in x.
#   Injections: repeaters 3j+1 4 -1 (G, facing south), 3j+2 4 3 (K, facing north), levers on
#   blocks behind them; CIN: CG (G start -1 4 0) and CK (K start 0 4 2).
#   Reads: comparators 3j+1 2 0 (@C0..@C4) facing east; spur wires 3j+1 2 1.
#   redsim-cli r024.redsim.json < experiments/redstone/R-024-analog-carry-lines.cli.txt
