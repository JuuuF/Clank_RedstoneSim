# R-019: wire on partial and special blocks; dropper quasi-connectivity (doc/redstone/records/R-019-wire-supports-and-dropper-qc.md)
#
# Rows 4 blocks apart (x = 10..12): a lever on a stone powers a wire lying on block X; a
# second wire on the floor east of X can only get power by stepping down from the first.
# X = stone, top slab, upside-down stairs, hopper, observer (facing up), glass, glowstone,
# lamp, copper bulb, target block, barrel. And a dropper (5 stone, facing a barrel) whose
# only power is a redstone block set next to the space above it at tick 2; a stone is
# placed beside the dropper at tick 10.
#   redsim-cli r019.redsim.json < experiments/redstone/R-019-wire-supports-and-dropper-qc.cli.txt
new size 64 force
note "R-019: power steps down only from wire lying on conductors; droppers are quasi-connected like pistons"
place 9 1 -24 stone
place 9 2 -24 lever face=floor
set 10 1 -24 stone
place 10 2 -24 redstone_wire
