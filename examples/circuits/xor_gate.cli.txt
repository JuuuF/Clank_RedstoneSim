# Circuit: XOR gate (two subtracting comparators facing each other). Contract: doc/redstone/circuits.md, "XOR gate".
#
# Module (box 0 1 -3 .. 6 3 2; inputs at the west and east ends, output raised to y=3):
#   @A    0 1 0   input wire A: drive it from the west (-1 1 0)
#   @B    6 1 0   input wire B: drive it from the east (7 1 0)
#   @OUT  3 3 -3  output wire on a stone at y=2 (power 12), pointing north into 3 3 -4
# Inside: C1 (2 1 0, facing east) = A - B, C2 (4 1 0, facing west) = B - A, both
# pointing into the stone 3 1 0. Each comparator's rear comes through a delay-1 repeater
# (1 1 0, 5 1 0) and its side through another (4 1 1 from A's loop south, 2 1 -1 from B's
# loop north), so all four paths take 4 ticks: no glitch when A and B change together.
# The output wire on the stone 3 1 0 climbs a stone stair (3 2 -1 .. 3 2 -3) over B's
# loop. The first version without rear repeaters dropped its output for 2 ticks when A
# and B swapped in one tick.
# Test harness: levers @LA, @LB beside the input wires.
#   redsim-cli xor_gate.redsim.json < examples/circuits/xor_gate.cli.txt
new size 16 force
note "XOR gate: @OUT is on while exactly one of @A, @B is on; 4 ticks on every edge, no glitches"
place 2 1 0 comparator out=east mode=subtract
place 4 1 0 comparator out=west mode=subtract
place 3 1 0 stone
place 0 1 0 redstone_wire
place 1 1 0 repeater out=east
line 0 1 1 to 0 1 2 redstone_wire
line 1 1 2 to 4 1 2 redstone_wire
place 4 1 1 repeater out=north
place 6 1 0 redstone_wire
place 5 1 0 repeater out=west
line 6 1 -1 to 6 1 -2 redstone_wire
line 5 1 -2 to 2 1 -2 redstone_wire
place 2 1 -1 repeater out=south
place 3 2 0 redstone_wire
set 3 2 -1 stone
set 3 2 -2 stone
set 3 2 -3 stone
place 3 3 -1 redstone_wire
place 3 3 -2 redstone_wire
place 3 3 -3 redstone_wire
label A 0 1 0 "input A: wire, driven from the west"
label B 6 1 0 "input B: wire, driven from the east"
label C1 2 1 0 "A minus B"
label C2 4 1 0 "B minus A"
label OUT 3 3 -3 "output: wire at y=3, pointing north"
group xor 0 1 -3 6 3 2 in @A A in @B B out @OUT OUT
prefab save xor_gate 0 1 -3 6 3 2
# harness
place -1 1 0 lever face=floor
place 7 1 0 lever face=floor
label LA -1 1 0 "test lever A"
label LB 7 1 0 "test lever B"
settle

target new truth "OUT = A xor B"
target truth truth @LA @LB -> @OUT rows 00:0 01:1 10:1 11:0

target new timing "4 ticks on every edge of either input"
target timing do at 2 use @LA
target timing do at 10 use @LB
target timing do at 20 use @LA
target timing do at 30 use @LB
target timing expect @OUT power=0 at 5
target timing expect @OUT power=12 during 6..13
target timing expect @OUT power=0 during 14..23
target timing expect @OUT power=12 during 24..33
target timing expect @OUT power=0 during 34..40

target new together "no glitch when A and B change in the same tick: both on, both off, swapped"
target together do at 2 use @LA
target together do at 2 use @LB
target together do at 12 use @LA
target together do at 12 use @LB
target together do at 22 use @LA
target together do at 32 use @LA
target together do at 32 use @LB
target together do at 42 use @LA
target together do at 42 use @LB
target together expect @OUT power=0 during 0..25
target together expect @OUT power=12 during 26..55

check
