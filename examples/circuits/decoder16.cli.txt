# Circuit: 1-of-16 signal-strength decoder. Contract: doc/redstone/circuits.md,
# "Signal-strength decoder".
#
# Module (box 0 1 0 .. 16 1 8): @IN, a barrel at 0 1 4 (replace it by the analog source:
# a container, or a block powered with the strength), is read by the comparator 1 1 4
# into a wire line along z=4 (cells c = 0..14 at x = c+2: power S - c). Every cell has a
# repeater tap on each side: T(c) = 15 while S >= c+1 (a thermometer code). Output m is
# a subtracting comparator with T(m-1) behind it and T(m) at its side: on only while
# S = m. Odd m on the south side, even m on the north; on each side the comparators
# alternate between a near row and a far row (with repeaters making up the delay), so no
# side wire touches two comparators. O0 = NOT T(0): a torch, padded by a delay-2 repeater.
#   @O0 .. @O15  output m: O0 at 2 1 0; even m >= 2 at m+1 1 0 (pointing north);
#                odd m at m+1 1 8 (pointing south). 15 while S = m, else 0.
# All outputs change 10 ticks after the input barrel (8 after the wire line), in one tick.
#   redsim-cli decoder16.redsim.json < examples/circuits/decoder16.cli.txt
