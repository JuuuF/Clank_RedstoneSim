# Circuit: hopper clock (long, item-counted periods). Contract: doc/redstone/circuits.md, "Hopper clock".
#
# Module (box 0 1 0 .. 9 2 4; it runs by itself):
#   @H1, @H2   4 1 3, 5 1 3  hoppers facing each other; H1 starts with N = 5 stone
#   @OUT       6 1 2         output: repeater out=east; on 8*N ticks, off 8*N-2 (period
#                            16*N-2: 78 ticks for N = 5)
#   @STOP      4 2 4         stop input: wire; while powered both hoppers are locked and
#                            the clock holds its state
# How it works: comparators C1, C2 read the hoppers; torches E1, E2 on the blocks they
# power are lit while their hopper is empty. Both torches feed one wire net into a copper
# bulb: the bulb toggles when a hopper becomes empty (never both at once) and ignores the
# torch turning off again. Comparator Q reads the bulb: lit -> it powers the stone 5 1 2,
# which locks H2 (H1 drains into H2), and the torch NQ on that stone goes out; unlit -> NQ
# locks H1 and H2 drains back. A wire on each hopper (fed by @STOP) locks both.
# Change N with `container 4 1 3 0 stone N` (N up to 64 in one slot; 1 gives period 15).
# Test harness: lever @LSTOP feeding the stop wire.
#   redsim-cli hopper_clock.redsim.json < examples/circuits/hopper_clock.cli.txt
new size 32 force
note "Hopper clock: @OUT on 8*N ticks, off 8*N-2 (N = 5 stone: period 78); power @STOP to freeze it"
place 4 1 3 hopper facing=east
place 5 1 3 hopper facing=west
container 4 1 3 0 stone 5
place 3 1 3 comparator out=west
place 6 1 3 comparator out=east
place 2 1 3 stone
place 7 1 3 stone
place 1 1 3 redstone_wall_torch facing=west
place 8 1 3 redstone_wall_torch facing=east
line 0 1 3 to 0 1 0 redstone_wire
line 1 1 0 to 4 1 0 redstone_wire
line 9 1 3 to 9 1 0 redstone_wire
line 8 1 0 to 6 1 0 redstone_wire
set 5 1 0 copper_bulb[lit=true,powered=true]
place 5 1 1 comparator out=south
place 5 1 2 stone
place 4 1 2 redstone_wall_torch facing=west
place 4 1 4 stone
place 4 2 3 redstone_wire
place 5 2 3 redstone_wire
place 4 2 4 redstone_wire
label H1 4 1 3 "hopper 1 (starts with the items)"
label H2 5 1 3 "hopper 2"
label C1 3 1 3 "reads H1"
label C2 6 1 3 "reads H2"
label E1 1 1 3 "torch: H1 empty"
label E2 8 1 3 "torch: H2 empty"
label BULB 5 1 0 "state: lit = H1 drains into H2"
label Q 5 1 1 "comparator reading the bulb: locks H2 through the stone 5 1 2"
label NQ 4 1 2 "torch: locks H1 while the bulb is off"
label STOP 4 2 4 "stop input: wire; power it to freeze the clock"
place 6 1 2 repeater out=east
label OUT 6 1 2 "output: repeater, on 8*N ticks, off 8*N-2"
group hopper_clock 0 1 0 9 2 4 in @STOP STOP out @OUT OUT
prefab save hopper_clock 0 1 0 9 2 4
# harness
place 4 1 5 stone
place 4 2 5 lever face=floor
label LSTOP 4 2 5 "test lever: stop"

target new run "N = 5: on 40 ticks, off 38, on 40 (period 78), from the build"
target run expect @OUT powered=false during 0..2
target run expect @OUT powered=true during 3..42
target run expect @OUT powered=false during 43..80
target run expect @OUT powered=true during 81..120
target run expect @OUT powered=false during 121..158
target run expect @H1 analog=0 at 35
target run expect @H2 analog=0 at 73

target new stop "STOP from 20 to 60 holds the state: the phase ends at 77 instead of 43 (the 8-tick cooldown keeps running while stopped)"
target stop do at 20 use @LSTOP
target stop do at 60 use @LSTOP
target stop expect @H1 enabled=false during 20..59
target stop expect @H2 enabled=false during 20..59
target stop expect @OUT powered=true during 3..76
target stop expect @OUT powered=false during 77..114
target stop expect @OUT powered=true at 115

check
