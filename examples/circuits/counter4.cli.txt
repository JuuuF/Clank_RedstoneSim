# Composition: 4-bit ripple counter from library modules. Contract: doc/redstone/circuits.md, "4-bit counter".
#
# Built only from examples/circuits/*.nbt (run from the repository root): per bit a
# t_flipflop (copper bulb + comparator Q) and, between bits, a not_gate whose input block
# the comparator powers; the gate's torch powers the next bulb. Bit k+1 toggles when bit
# k falls (the torch turns on), so the bulbs count rising edges at @IN.
#   @IN   -1 1 0   test lever beside the first bulb (any rising edge counts)
#   @Q0..@Q3       comparators: bit k at x = 4k+1 (15 = 1)
# The pasted modules keep their states (strict paste, no updates): each later bulb sits
# unlit and unpowered next to a lit torch, and stays so until that torch changes, so the
# counter starts at 0. (A bulb *placed* next to a lit torch would light: placement
# counts as a rising edge.)
#   redsim-cli counter4.redsim.json < examples/circuits/counter4.cli.txt
new size 32 force
note "4-bit ripple counter: rising edges at @IN count up in @Q0..@Q3 (bit k settles 2+4k ticks after the edge)"
import examples/circuits/t_flipflop.nbt at 0 1 0
import examples/circuits/not_gate.nbt at 2 1 0
import examples/circuits/t_flipflop.nbt at 4 1 0
import examples/circuits/not_gate.nbt at 6 1 0
import examples/circuits/t_flipflop.nbt at 8 1 0
import examples/circuits/not_gate.nbt at 10 1 0
import examples/circuits/t_flipflop.nbt at 12 1 0
place -1 1 0 lever face=floor
label IN -1 1 0 "test lever: count its rising edges"
label Q0 1 1 0 "bit 0"
label Q1 5 1 0 "bit 1"
label Q2 9 1 0 "bit 2"
label Q3 13 1 0 "bit 3"
group counter4 0 1 0 13 1 0 in 0 1 0 IN out @Q0 Q0 out @Q1 Q1 out @Q2 Q2 out @Q3 Q3
prefab save counter4 0 1 0 13 1 0
settle
