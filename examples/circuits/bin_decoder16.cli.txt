# Composition: binary 4-to-16 decoder: output N on while B3 B2 B1 B0 = N. Contract:
# doc/redstone/circuits.md, "Binary decoder". Run from the repository root (it imports
# examples/circuits/decoder16.nbt and dac4.nbt).
#
# dac4 turns the four bits into the strength N on its OUT stone 4 1 0; decoder16 is pasted
# so that this stone is its input (its corner at 4 1 -4; the dac paste, done second,
# replaces the decoder's input barrel with the stone).
#   @L0..@L3  levers west of dac4's inputs (its ports at x = -1)
#   @O0..@O15 the decoder's outputs: O0 6 1 -4, even m at m+5 1 -4 (facing north), odd m
#             at m+5 1 4 (facing south)
# Latency 22 ticks (12 + 10); several bits may change together: no other output flashes.
#   redsim-cli bin_decoder16.redsim.json < examples/circuits/bin_decoder16.cli.txt
new size 48 force
note "Binary 4-to-16 decoder (dac4 + decoder16): output @ON is on while the levers B3..B0 read N, 22 ticks after a change"
import examples/circuits/decoder16.nbt at 4 1 -4
import examples/circuits/dac4.nbt at -1 1 -5
place -2 1 -2 lever face=floor
place -2 1 2 lever face=floor
place -2 1 -4 lever face=floor
place -2 1 4 lever face=floor
label L3 -2 1 -2 "bit 3 (lever)"
label L2 -2 1 2 "bit 2 (lever)"
label L1 -2 1 -4 "bit 1 (lever)"
label L0 -2 1 4 "bit 0 (lever)"
label N 4 1 0 "the strength N (output of dac4, input of decoder16)"
label O0 6 1 -4 "on while N = 0"
label O1 6 1 4 "on while N = 1"
label O2 7 1 -4 "on while N = 2"
label O3 8 1 4 "on while N = 3"
label O4 9 1 -4 "on while N = 4"

label O12 17 1 -4 "on while N = 12"
label O13 18 1 4 "on while N = 13"
label O14 19 1 -4 "on while N = 14"
label O15 20 1 4 "on while N = 15"
