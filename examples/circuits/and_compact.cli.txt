# Circuit: compact AND (subtracting comparator). Contract: doc/redstone/circuits.md, "Compact AND".
#
# Module (box 0 1 0 .. 1 1 3, output east):
#   @A    0 1 0  input repeater A (out=east, delay 1) into the comparator's rear: drive it
#                from the west (-1 1 0): lever, wire, repeater, powered block
#   @B    1 1 3  input block B: power it (attach a lever on its south face, or point a
#                repeater, comparator or wire into it from the south or east/west)
#   @OUT  1 1 0  comparator out=east, subtract: 15 while A and B are on
# Inside: a wall torch 1 1 2 on @B (facing north) powers the wire 1 1 1 at the
# comparator's side: side = not B, OUT = A - side. The repeater on A makes both paths 4
# ticks long; without it (a wire at 0 1 0) A was 2 ticks faster and the output glitched
# for 2 ticks when A rose as B fell (R-010).
# Test harness: lever @LA west of @A, lever @LB on @B's south face.
#   redsim-cli and_compact.redsim.json < examples/circuits/and_compact.cli.txt
new size 16 force
note "Compact AND: comparator @OUT = A minus (not B); 4 ticks from either input, no glitches"
place 0 1 0 repeater out=east
place 1 1 0 comparator out=east mode=subtract
place 1 1 3 stone
place 1 1 2 redstone_wall_torch facing=north
place 1 1 1 redstone_wire
label A 0 1 0 "input A: repeater into the comparator rear"
label B 1 1 3 "input block B"
label NB 1 1 2 "torch: not B"
label OUT 1 1 0 "output: comparator"
group and_compact 0 1 0 1 1 3 in @A A in @B B out @OUT OUT
prefab save and_compact 0 1 0 1 1 3
# harness
place -1 1 0 lever face=floor
place 1 1 4 lever face=wall facing=south
label LA -1 1 0 "test lever A"
label LB 1 1 4 "test lever B"
settle

target new truth "OUT = A and B"
target truth truth @LA @LB -> @OUT rows 00:0 01:0 10:0 11:1

target new timing "4 ticks each way from either input"
target timing do at 2 use @LA
target timing do at 10 use @LB
target timing do at 20 use @LB
target timing do at 30 use @LB
target timing do at 40 use @LA
target timing expect @OUT power=0 at 13
target timing expect @OUT power=15 during 14..23
target timing expect @OUT power=0 during 24..33
target timing expect @OUT power=15 during 34..43
target timing expect @OUT power=0 at 44

target new swap "no glitch when one input rises as the other falls"
target swap do at 2 use @LB
target swap do at 10 use @LA
target swap do at 10 use @LB
target swap do at 20 use @LA
target swap do at 20 use @LB
target swap expect @OUT power=0 during 0..40

check
