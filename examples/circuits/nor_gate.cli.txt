# Circuit: NOR gate (two wires into a block, torch out). Contract: doc/redstone/circuits.md, "NOR gate".
#
# Module (box 0 1 0 .. 1 1 2, output east):
#   @A    0 1 0  input wire: drive it from the north (0 1 -1)
#   @B    0 1 2  input wire: drive it from the south (0 1 3)
#   @X    0 1 1  the block both wires point into
#   @OUT  1 1 1  wall torch on @X's east face: on while neither A nor B is on
# Test harness: levers @LA (0 1 -1) and @LB (0 1 3).
#   redsim-cli nor_gate.redsim.json < examples/circuits/nor_gate.cli.txt
new size 16 force
note "NOR gate: @OUT (torch) is on while neither @A nor @B is on; 2 ticks each way"
place 0 1 1 stone
place 0 1 0 redstone_wire
place 0 1 2 redstone_wire
place 1 1 1 redstone_wall_torch facing=east
label A 0 1 0 "input A: wire, driven from the north"
label B 0 1 2 "input B: wire, driven from the south"
label X 0 1 1 "the block both inputs power"
label OUT 1 1 1 "output: wall torch"
group nor 0 1 0 1 1 2 in @A A in @B B out @OUT OUT
prefab save nor_gate 0 1 0 1 1 2
# harness
place 0 1 -1 lever face=floor
place 0 1 3 lever face=floor
label LA 0 1 -1 "test lever A"
label LB 0 1 3 "test lever B"
settle

target new truth "OUT = not (A or B)"
target truth truth @LA @LB -> @OUT rows 00:1 01:0 10:0 11:0

target new timing "2 ticks off and on"
target timing do at 2 use @LA
target timing do at 10 use @LB
target timing do at 20 use @LA
target timing do at 30 use @LB
target timing expect @OUT lit=true at 3
target timing expect @OUT lit=false during 4..31
target timing expect @OUT lit=true at 32

check
